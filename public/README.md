# Acqui Brand Kit

Flat, geometric, tilted archway symbol based on the latest approved visual direction.

## Files
- acqui-icon.svg/png: primary icon, transparent background
- acqui-wordmark.svg/png: horizontal icon + lowercase acqui name
- acqui-icon-white.svg/png: monochrome white variant for dark backgrounds
- acqui-icon-monochrome.svg/png: single-color navy variant
- acqui-wordmark-dark.svg/png: light wordmark for dark backgrounds
- favicon-*.png: common app icon sizes
- brand-colors.css: brand tokens

## Palette
- Navy #102C45
- Blue #2867E8
- Pale blue #B8D0FC
- Cream #F8F6F2

## Notes
The SVG is genuine editable vector geometry, reconstructed from the approved concept rather than an embedded raster image. The wordmark uses font-family fallbacks (Inter/Arial/Helvetica); for exact reproduction across systems, outline the text in a vector editor before sending to print. This is a refined vector interpretation, not a pixel-identical vectorization of the generated image.
